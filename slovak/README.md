# Slovak lemma table

`lemma.tsv` maps inflected Slovak word forms to their dictionary form, one
`form<TAB>lemma` line per lowercase form, sorted bytewise by form. The RAG
analyzer looks a Slovak token up here before its light stemmer runs, which
reaches the forms the suffix rules cannot (`psovi` → `pes`, `ľuďmi` → `ľudia`).

It is derived from the [hunspell-sk](https://github.com/sk-spell/hunspell-sk)
dictionary, commit `ee4ffc39c1955411293dc0cf6263daa344fd18a4`, and is
distributed under that dictionary's licence, the Mozilla Public License 2.0
(`LICENSE` in this directory).

The table is generated by `tools/generate_slovak_lemma_table.py` in
[infinity](https://github.com/infiniflow/infinity):

```
git clone https://github.com/sk-spell/hunspell-sk
uv run tools/generate_slovak_lemma_table.py --hunspell-sk hunspell-sk --output slovak/lemma.tsv
```

It holds only the forms whose lemma changes the analyzer's output, leaving
negated forms, ambiguous forms, forms shorter than four letters and a short
list of mis-analysed forms to the stemmer.
